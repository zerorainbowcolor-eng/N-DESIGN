# トップページ 引き継ぎメモ（Claude Code用）

## これは何か
採用サイト型トップページの静的実装。ページ構成と動きの種類は参考サイトに倣い、
文言・画像・配色・レイアウトの細部は新規に作っている。

```
top-page/
├─ index.html
├─ css/style.css
├─ js/hero.js   … FVの背景スライダー（素のWebGL + GSAP）
├─ js/main.js   … ヘッダー、SPメニュー、スクロール演出、Swiper
└─ images/      … slide01 だけ支給写真。ほかは全部ダミー
```

外部ライブラリ（CDN）：GSAP 3.12.5 + ScrollTrigger、Swiper 11、Google Fonts（Zen Kaku Gothic New / Outfit）

## 確認方法
必ずローカルサーバー経由で開く。`file://` だとWebGLの制限で写真が読めず、FVがダミー画像になる。

```
npx serve top-page
```

## ページ構成
1. ヘッダー：固定。FV〜aboutの上では白文字・透明、抜けると白地に切り替わる。1080px以下はハンバーガーメニュー
2. FV：背景は画面固定のcanvas。ノイズで写真がにじむように切り替わる。コピー、枚数表示＋進行バー＋一時停止ボタン、お知らせ、採用リンク
3. about：FVと同じ固定背景の上に載る。スクロールに合わせて紺の幕が濃くなる
4. 事業案内：フェードで切り替わるスライダーと、右の番号つきリストが連動（ホバー／フォーカスで該当スライドへ）
5. 働くひと：横に流せるカード列（前後ボタン＋進行バー）と、流れる英字
6. キャリア／働く環境：写真入りの大きなリンクカード2枚
7. ギャラリー：流れる大きな英字と、流れる写真の列
8. 採用CTA
9. フッター

## 差し替える場所
- 文言：2026.09.21に本番原稿（株式会社アクスコンサルティング／コンサルティング編）を実装済み。枠ごとの文字数上限は `原稿指示プロンプト.md` にまとめてある
  - FVメインコピーのサブ案（複雑な時代に／確かな指針を）は `index.html` のコメントに残してある
  - **住所は架空のダミー**（丸の内1-1-1／梅田2-2-2）。どちらも実在する街区なので、公開前に必ず実際の住所へ差し替える。`index.html` のフッターにコメントあり
  - リンク先はまだ全部 `#`。「会社を知る」「企業サイト」など下層ページができたら差し替える
- ロゴ：`.logo-mark` と `.logo-text` が仮のロゴ（現在はテキストで `GROWTH DESIGN`）。SVGに差し替える
- 画像：FV以外はまだ全部ダミー。探す時の仕様は `画像指示プロンプト.md`
  - FVは2026.09.21にスーツ姿の男性写真へ差し替え。**2・3枚目が未定のため、slide01〜03に同じ画像を入れてある**。切り替わっても絵は変わらず、数字だけ 01→02→03 と回る。2・3枚目が決まったら `slide02/03.jpg` と `_sp` を上書きするだけでよい
  - 元画像は1152×896と小さい。PCは `1152×648`（上端そろえの16:9切り）、SPは `672×896`（頭部中心 x=710 を中央に置いた3:4切り）。**フルブリードのFVとしては解像度不足**なので、可能なら横2000px以上の元データに差し替える
- 画像：`images/` のファイルを同名で上書きすれば反映される
  - FVは `slide01〜03.jpg`（PC、横2000px目安）と `slide01〜03_sp.jpg`（SP、3:4の縦）。枚数は `js/hero.js` の `CONFIG.slides` で増減。1枚にすると静止FVになり、数字とバーは自動で隠れる
- 色・余白：`css/style.css` 冒頭の `:root`
- FVの動き：`js/hero.js` 冒頭の `CONFIG`（`noiseScale` 模様の細かさ / `softness` 境界のぼかし / `interval` / `duration`）

## FV写真についての注意
- 支給写真は人物が左〜中央にいるので、PCではコピーを右側（青いビルの上）に置いている。写真を替える時はコピーの位置も見直す
- SP用は顔を中心に3:4で切り出し、下側に暗いグラデーションをかけてコピーを載せている
- 人物の顔が大きい写真同士をノイズで切り替えると、途中で顔がまだらに見えやすい。2・3枚目は風景や引きの写真が無難。気になる場合は `softness` を 1 以上にするとクロスフェードに近づく
- ストックフォトを使う場合は、Web利用がライセンスの範囲内か確認する

## ブラウザ確認の結果（2026.09.21 / Chromium・ローカルサーバー）
確認した幅：375 / 768 / 1080 / 1081 / 1440。コンソールエラーなし、画像の404なし、横スクロールなし。

済み：
- FVのシェーダー表示。PCは `slide01〜03.jpg`、SPは `_sp` 付きを読み分けている。切り替え・枚数表示・進行バー・一時停止ボタンいずれも動作
- 「働くひと」上下の弧は PC / SP とも意図どおりの見え方
- `.team__progress` の位置と黄緑の伸び方、前後ボタンの連動
- 事業案内スライダーと右リストの連動（ホバー／フォーカス）
- ヘッダーの白地切り替え、1080px以下のハンバーガー（1080 / 1081 で正しく切り替わる）
- SPメニューの開閉、Escで閉じる、背面スクロールのロック

直したもの：
- `.team` の `overflow: hidden` を `clip` に変更。hidden のままだと上下の弧（`left:-10%; width:120%`）が作る横方向のはみ出しで `.team` 自体がスクロール可能になり、前後ボタンでスライドにフォーカスが移った時にブラウザがセクションごと左へ送ってしまい、見出しが画面外に消えていた
- 働くひとの前後ボタンの `aria-label`。Swiperのa11yが英語の既定文で上書きするので、`a11y.prevSlideMessage / nextSlideMessage` で日本語を渡した

## FVの見せ方を変更（2026.09.21）
支給写真（`slide01`）だと1080px以下でコピーが写真に埋もれて読めなかったため、参考イメージに合わせて作り直した。

- コピーを右寄せから**左寄せ**に変更（`.hero` の `justify-content`）。幅も `min(54vw, 780px)` に広げた
- 見出しを大きく（`clamp(1.625rem, 4.6vw, 4.25rem)`）。英字サブも一段大きく、太さを300→500に
- `.hero::before` を作り直し。**写真全体に青い幕**（`rgba(17, 94, 196, 0.16)`）を敷いた上に、左ほど濃くなる幕＋上下の幕を重ねている。これで写真の明暗に関係なく白文字が読める
  - 幕は4枚重なるので、見た目の濃さは各値の足し算ではなく合成値。**合成値でコピーが乗る左端0%〜60%が60%→45%、写真を見せたい右側は18%** という配分にしてある
  - 2026.09.21に「ギリギリまで薄く」調整済み。**これ以上薄くすると、明るい写真の上で白コピーが沈む**（大きい太字の下限、コントラスト比およそ3:1）。濃くするぶんには問題ない
- SP（767px以下）は下からの幕を上まで伸ばした。コピーが画面の下半分に来るため

375 / 768 / 1440 で確認済み。幕の濃さは `.hero::before` の4つの値だけで調整できる。
写真を差し替えた時も、青い幕があるぶん以前ほど写真を選ばない。

まだ手を付けていない参考イメージ寄りの要素：お知らせ帯をブランドブルーの角帯にする、一時停止ボタンを青丸にする、など。
